# Applications

## Presentations
- There are two presentations, minimal and pretty
- A presentation determines what is seen and how it is touched
- A presentation determines no rule
- Text is entered only to name something
- Text entry works with an on-screen keyboard
- The minimal presentation asks least of the machine it runs on

## Deliveries
- There are two deliveries, desktop and web
- Every presentation has a desktop game and a web game
- A desktop game is single player
- A web game is multiplayer
- A player using one presentation and a player using the other can be in the same match

## Desktop
- A desktop game has one human
- Every opponent in a desktop game is an AI player
- The local player chooses the number of opponents
- The number of opponents is at least one
- A desktop game has no network
- A desktop game has no authentication
- A script launches a desktop game
