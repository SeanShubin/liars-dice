# AI Managed Notes

Working memory for AI assistants across sessions. The user generally does not read or
edit anything in this directory.

## Rules

- **Nothing here is authoritative.** If a note contradicts the
  [specification](/specification/README.md), the specification is right and the note is
  stale. Fix the note.
- Notes record *observations and derived understanding*, never new ideas about what the
  game or system should be. Those belong to the user.
- Anything the user needs to decide goes in [OPEN-QUESTIONS.md](/OPEN-QUESTIONS.md), not
  here, because the user does not read this directory.
- Every note states what it is for in its first line, so a cold session can judge
  relevance without reading the whole file.
- Delete notes that have gone stale rather than letting them rot.

## What Belongs Here

- **session-log.md** — what was done, what was in flight, what to pick up next.
- **inferences.md** — things assumed because the specification was silent, so a later
  session does not re-derive them differently. Each entry links to the corresponding
  open question.
- **conventions-observed.md** — patterns noticed in the user's writing and preferences
  that are not written down anywhere official.
- **terminology-drift.md** — places where the same concept is named two ways, pending a
  glossary fix.

## What Does Not Belong Here

- Specification content.
- Implementation plans.
- Questions for the user.
- Copies of information that lives elsewhere. Link instead.
